# Apparel 运营知识库

## 平台规则
### 淘宝
- 标题含核心品类词 + 风格词 + 适用场景，如「复古牛仔外套 春秋」。
- 主图展示正面/背面/细节，尺码表必填。
- 详情页强调面料成分与版型（显瘦/宽松）。

### 抖音
- 短视频展示上身效果与穿搭场景，强调「显瘦」「百搭」。
- 口播突出面料触感与性价比。
- 挂车文案用「同款」「穿搭」类词引流。

### 小红书
- 笔记重穿搭灵感与身材修饰技巧，像博主分享。
- 封面图突出风格标签（通勤/甜酷/老钱风）。
- 标签用风格词 + 身材词，如 #梨形身材 #通勤穿搭。

## 违禁词
- 虚假宣称：正品、专柜同款、原单（无授权不得宣称）。
- 绝对化：最显瘦、第一潮牌（避免）。
- 材质误导：纯棉（混纺不得标纯棉）、羊绒（非 100% 不得标）。

## SEO 建议
- 核心关键词：牛仔外套、通勤穿搭、显瘦、春秋、复古。
- 标题公式：风格 + 品类 + 场景，如「复古牛仔外套 春秋 通勤显瘦」。
- 长尾词：小个子穿搭、梨形身材、学生党平价。
