# Home 运营知识库

## 平台规则
### 淘宝
- 标题前 30 字权重最高，核心词前置；避免堆砌无关词。
- 主图白底实物图，第 2-3 张放场景图与细节图。
- 详情页强调材质、容量、保温时长等可量化参数。

### 抖音
- 短视频种草重使用场景与情绪价值，前 3 秒抓眼球。
- 口播避免绝对化，强调「真实体验」「自用分享」。
- 挂车文案突出性价比与限时活动。

### 小红书
- 笔记重生活方式与成分/材质科普，语气亲切像朋友推荐。
- 封面图需有信息点（如「办公室续命杯」）。
- 标签用 3-5 个精准垂类词，避免泛词。

## 违禁词
- 绝对化用语：最、第一、国家级、顶级（避免）。
- 功效承诺：根治、秒白、100% 保温（避免，保温需给具体时长）。
- 虚假材质：医用级、食品级（无资质不得宣称）。

## SEO 建议
- 核心关键词：保温杯、便携水杯、办公室水杯、大容量、316 不锈钢。
- 标题公式：场景 + 材质 + 人群，如「办公室保温杯 316 不锈钢 便携」。
- 长尾词：送男友/送闺蜜、开车专用、健身补水。
