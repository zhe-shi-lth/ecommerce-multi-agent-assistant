# Beauty 运营知识库

## 平台规则
### 淘宝
- 详情页必须标明成分表与净含量，特殊功效需对应资质。
- 主图避免 before/after 对比图（易被判夸大）。
- 关键词突出成分（如烟酰胺、玻尿酸）与肤质（油皮/干皮）。

### 抖音
- 短视频可演示上脸效果，但不得出现「立竿见影」类承诺。
- 达人种草重成分科普与肤感描述。
- 直播话术规避「治疗」「消炎」等医疗用语。

### 小红书
- 笔记重成分党分析、使用感受与肤质适配，像闺蜜分享。
- 封面突出「成分/功效」信息点。
- 标签用成分词 + 肤质词，如 #油皮护肤 #成分党。

## 违禁词
- 医疗用语：治疗、消炎、药用、抗菌（无资质不得宣称）。
- 功效承诺：美白、祛斑、淡纹（需特妆/功效评价资质）。
- 绝对化：纯天然、零添加、100% 安全（避免）。

## SEO 建议
- 核心关键词：保湿、成分护肤、敏感肌、精简护肤、玻尿酸。
- 标题公式：功效 + 成分 + 肤质，如「敏感肌保湿 玻尿酸 精简护肤」。
- 长尾词：换季泛红、学生党护肤、早 C 晚 A 搭配。
