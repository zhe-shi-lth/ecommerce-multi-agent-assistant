# 正式上线验收清单

## 范围

公司/租户/角色数据隔离已经完成。三方平台官方 API 字段映射与商家授权联调仍是独立上线里程碑，其余生产工程项必须全部通过。

## 必过项

- [ ] `APP_ENV=production`，JWT、服务密钥、设置加密密钥均为独立随机值且不少于 32 字符。
- [ ] `SWAGGER_ENABLED=false`，数据库不暴露公网，HTTPS 由网关终止。
- [ ] `MEDIA_ALLOWED_HOSTS` 仅包含已接入模型供应商的媒体域名。
- [ ] Java 全量测试、Python 全量测试、前端构建和 E2E 全绿。
- [ ] Flyway 升级到最新版本，无失败迁移。
- [ ] 平台任务无长期 `RUNNING`，`FAILED`/`NEEDS_RECONCILIATION` 已处理。
- [ ] 执行 `scripts/backup.ps1`，并在隔离环境用 `scripts/restore.ps1` 完成恢复演练。
- [ ] 恢复后执行 `scripts/production_smoke.py` 通过。
- [ ] 日销量并发测试通过，库存、采购、售后状态机测试通过。
- [x] API Key 接口仅返回掩码，磁盘凭证为 `enc:v1:` 密文；AI 设置按企业保存，平台凭证按店铺保存。
- [ ] 使用两个企业、两个店铺账号执行隔离验收，商品、订单、库存、供应商、采购和审计均不可跨租户读取。
- [x] 使用老板创建员工，为员工分配一个或多个店铺及具体权限后验证基础接口权限矩阵。
- [ ] 完成查看、创建、编辑、审核、执行、平台同步等全部细粒度权限的业务场景验收。
- [ ] 每个店铺分别完成平台 OAuth 授权，确认凭证密文和发布/拉单/发货任务均归属正确店铺。

## 发布后检查

- [ ] Java、Python、前端健康检查正常。
- [ ] 发布和发货各执行一笔，平台任务最终为 `COMPLETED`。
- [ ] 日志中无默认密钥、明文 Token、完整请求凭证。
- [ ] 监控平台任务失败率、HTTP 5xx/429、数据库连接池和磁盘容量。
