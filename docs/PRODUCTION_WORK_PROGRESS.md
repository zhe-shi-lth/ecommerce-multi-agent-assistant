# 生产工项完成记录

完成时间：2026-08-16

## 完成范围

本轮完成生产工程能力，并在后续版本补齐公司、店铺、成员、角色和租户数据隔离：

- 发布与发货平台任务：幂等键、并发认领、外部成功快照、提交后完成、退避重试、人工对账和超时任务识别。
- 日销数据：PostgreSQL 原子累计与商品/平台/日期唯一约束。
- 前端可观测性：运营计划和订单详情展示平台任务，后台状态每 5 秒平滑更新，可发起人工重试。
- 安全：敏感设置加密落盘与接口掩码、旧明文自动迁移、生产默认密钥拦截、媒体 SSRF/MIME/大小限制、用户写请求限流。
- 运维：Actuator 健康/指标、数据库/媒体/设置备份恢复脚本、隔离恢复验证脚本、恢复后冒烟脚本和上线检查清单。
- 测试：平台任务事务与并发测试、Python 安全测试、Playwright 关键页面与鉴权 E2E。
- 依赖：Vite、React Router 等前端依赖升级，`npm audit` 无已知漏洞；Python `uv.lock` 已同步。
- 文档：README 和 PLAN 已统一为三平台均可发起任务、生成失败不返回假数据、真实模式不回退模拟数据。
- 多租户：公司、店铺、成员关系、角色权限、JWT 租户上下文、业务数据隔离和真实操作人审计。
- 设置分层：AI 文案/图片/视频/审核/监控配置按企业保存；小红书、淘宝、抖音凭证按店铺加密保存，接口不返回明文，Java/Python 调用链传递租户上下文。
- 兼容迁移：旧版本按企业和店铺保存的 AI 设置，会在首次访问企业设置时自动迁移为企业级设置。
- 组织管理：超级管理员创建企业；老板管理店铺、成员、角色和成员状态；用户可切换所属企业/店铺。
- 权限细化：增加创建商品、创建订单、创建库存、执行生成任务、同步平台订单和平台发布权限，并在后端入口校验。
